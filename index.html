Multi-agent Live ↗

Mad World

Multi Agent Experimentation Lab

A self-initiated exploration into multi-agent discussion rooms. Built on the hypothesis that single-model chat suffers from sycophancy — models agree with the user — and that putting heterogeneous models in structured disagreement, each grounding claims with independent web search, produces more honest, better-evidenced answers than a similar single model alone.
